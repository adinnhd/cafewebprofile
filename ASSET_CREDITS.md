## Font dan ikon

- **Fraunces** dan **DM Sans** di-self-host melalui paket Fontsource. Lisensi SIL Open Font License 1.1 disertakan dalam paket masing-masing dan didistribusikan dalam `public/licenses/fraunces.txt` dan `public/licenses/dm-sans.txt`. Sumber: [Fraunces](https://fontsource.org/fonts/fraunces), [DM Sans](https://fontsource.org/fonts/dm-sans).
- **Logo header/footer:** `public/logo-tigasegi.png` disediakan pengguna dan dipasang sesuai permintaan. File sumber dipertahankan; CSS hanya menyembunyikan padding transparan agar logo terbaca pada ukuran navigasi. Penggunaan dalam demo tidak menyiratkan persetujuan atau kerja sama resmi dengan pemilik merek.
- **Simbol pada stempel hero:** memakai file logo yang sama melalui crop viewport SVG di `Hero.astro`, hanya menampilkan segitiga tanpa tulisan “Tigasegi Coffee”. Bentuk simbol berasal langsung dari gambar; file asli tidak diubah.
- **Lucide** digunakan melalui `@lucide/svelte`, lisensi ISC dengan sebagian ikon turunan Feather berlisensi MIT; [sumber dan lisensi](https://lucide.dev/license). Teks lisensi lengkap didistribusikan dalam `public/licenses/lucide.txt`. Ikon SVG statis menggunakan bentuk geometris sederhana.
- **Favicon** dan motif segitiga merupakan SVG konsep original dalam proyek, bukan logo resmi bisnis.
